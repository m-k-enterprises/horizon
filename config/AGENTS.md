# Config Files

## `settings_schema.json`

Guidelines and examples for organizing and structuring the Shopify theme settings schema.

Settings Schema Rules: [Theme Settings](../.cursor/rules/theme-settings.mdc)

## `settings_data.json`

Treat `settings_data.json` as autogenerated persisted theme state.

Do not apply settings schema organization rules to this file.
Keep manual edits exceptional and minimal, and preserve valid JSON because Shopify admin or related systems may overwrite the file.
