# Sections

## `*.liquid`

Follow these standards when developing Liquid sections and their related schemas.

Liquid Rules: [Section Development Standards](../.cursor/rules/sections.mdc)
Schema Rules: [Schema Standards](../.cursor/rules/schemas.mdc)

## `header-group.json` and `footer-group.json`

Treat section-group JSON files as autogenerated configuration.

Do not apply Liquid section standards to these files.
Keep manual edits exceptional and minimal, and preserve valid JSON when an explicit change is required.
